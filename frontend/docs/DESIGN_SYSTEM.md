# ☕ Coffee Companion - ROWA-Inspired Design System

## 🎨 Design Aesthetic (Inspired by ROWA Coffee)

**Overall Feel:** Minimalist + Industrial + Modern
- **Fonts:** Poppins (clean, modern sans-serif)
- **Colors:** Black, white, warm taupe accents
- **Borders:** Sharp, clean lines (0px border-radius)
- **Spacing:** Generous, breathing room
- **Typography:** Large, bold headers with generous letter-spacing

---

## 🎯 Design System

### Color Palette
```
Primary Black:      #0A0A0A (text, strong elements)
Primary White:      #FFFFFF (backgrounds)
Accent Warm:        #C9A87C (coffee color, highlights)
Accent Brown:       #6B4423 (secondary accents)
Text Light:         #666666 (secondary text)
Border:             #E0E0E0 (clean dividers)
Background Alt:     #F9F9F9 (subtle contrast)
```

### Typography
- **Font Family:** Poppins (Google Fonts)
- **H1:** 3.5rem, weight 700, letter-spacing -1px
- **H2:** 2.2rem, weight 700
- **H3:** 1.5rem, weight 600
- **Body:** 0.95rem, weight 400
- **Caption:** 0.9rem, weight 400, color #666

### Components
- **Cards:** Flat design, 1px solid #E0E0E0 border, 0px radius
- **Buttons:** Black background, white text, hover inverts
- **Inputs:** Clean borders, no shadow
- **Tabs:** Bottom border indicator in #C9A87C
- **Info Boxes:** Left border accent (3px)

## ✨ Key Features

✅ **No gradients** - Flat, minimalist design
✅ **Sharp corners** - 0px border-radius throughout
✅ **Clean typography** - Poppins with generous spacing
✅ **Black & white focus** - With warm taupe accents
✅ **Minimal shadows** - Only subtle borders
✅ **Strong contrast** - Dark text on light backgrounds
✅ **Industrial feel** - Like ROWA Coffee aesthetic

## 🚀 UI Components

### Buttons
```
Primary: Black bg, white text, hover inverts
Style: Flat, no shadow, uppercase when needed
```

### Cards
```

Padding: 2rem
Shadow: None (border only)

```
